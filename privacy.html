Privacy Policy

TUKO Personal Assistant · Last updated: October 31, 2026

TUKO is a private, single-user personal assistant. It is operated by its owner for the owner's own use and is not offered to the public. This policy explains what Google user data TUKO accesses, how it is used, and what choices the owner has.

1. Who uses TUKO

TUKO connects only to the Google account of its owner, with the owner's explicit permission given through Google's standard sign-in and consent screen. It does not accept other users and does not create accounts.

2. Google data TUKO accesses

TUKO requests read-only access:

  • Gmail (read-only): searching and reading messages and threads in the owner's mailbox, including sent mail, such as senders, recipients, subjects, dates and message text.
  • Google Calendar (read-only): the list of calendars available to the owner and their events, such as titles, times, locations and descriptions.
  • Basic account information: the owner's email address, used to identify the connected account.

TUKO cannot send, delete or modify email, and cannot create, change or delete calendar events, through its Google access.

Messages and calendars can contain information about other people, such as senders or event participants. That information is used only as part of the owner's own briefing.

3. How the data is used

Google data is used only to provide TUKO's personal-assistant features to the owner:

  • preparing a daily briefing that summarises upcoming events, schedule conflicts, messages that need a reply and other items that need the owner's attention;
  • confirming that emails TUKO prepared for the owner have arrived in the owner's mailbox;
  • answering questions the owner asks TUKO about their own email and calendar.

Briefings and answers go only to the owner.

4. Where the data is processed

  • TUKO runs on a private server controlled by the owner. Google data is retrieved and handled there.
  • To write the briefing, relevant excerpts of email and calendar data are sent to third-party AI model providers (currently OpenAI and Anthropic) through their APIs. The providers process this content to generate the text and return it to TUKO.
  • Google data is not shared with anyone else.

5. What TUKO does not do

  • It does not sell Google user data or any other personal data.
  • It does not use the data for advertising, and it does not share it with advertisers or data brokers.
  • It does not use Google user data to develop, improve or train generalised AI or machine learning models.
  • It does not allow people to read the data, except the owner, or where needed for security, to comply with law, or with the owner's consent.

6. Google API Services User Data Policy

TUKO's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Storage

Generated briefings are saved on the owner's private server. The authorisation that lets TUKO read Google data is stored on the same server. No automatic deletion schedule is currently defined. The owner can delete stored briefings at any time.

8. Revoking access

Access can be revoked at any time on the Google Account Third-party connections page. After that, TUKO can no longer read Gmail or Google Calendar.

9. This website

This website has no analytics, advertising or tracking scripts and sets no cookies. It is hosted on GitHub Pages, which may log basic technical information such as IP addresses under GitHub's privacy statement.

10. Changes

If this policy changes, the updated version will be posted on this page with a new date.
